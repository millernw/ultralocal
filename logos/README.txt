ULTRA LOCAL BRAND KIT
goultralocal.com

Start with 06-brand-guide/ultralocal-brand-guide.pdf. It shows every version and when to use it.

FOLDERS
01-logo-stacked      Primary logo. ULTRA over Local with the arrow.
02-logo-horizontal   Wide version for website headers, email signatures, letterhead.
03-icon              Script L + arrow. For spaces too small for the full logo.
04-favicon           Browser tab and phone home-screen icons, plus the code to install them.
05-social            Profile picture and cover/banner images sized for each platform.
06-brand-guide       Brand guide PDF: logo use, colors, fonts, clear space, don'ts.

FILE TYPES
svg   Vector. Use on the website and send to sign, vinyl and apparel shops. Scales to any size.
pdf   Vector. Send to printers who ask for print-ready or vector art (they can open it in Illustrator).
png   Picture file with a transparent background. Use in Word, Canva, social posts, email.
      -600w / -1200w / -2400w = pixel width. On a website, use a PNG about 2x the size it displays, or better, the SVG.

COLOR VERSIONS
color       Teal, pink, gold. For white and light backgrounds.
neon        Light tube colors. For navy and dark backgrounds.
neon-glow   The glowing neon look. SCREENS ONLY. No PDF is included on purpose: printers, vinyl cutters
            and embroidery machines cannot reproduce a glow.
black       One color. For single-ink printing, stamps, engraving.
white       One color. For placing over photos or brand colors.

Favicon:                      everything in 04-favicon + head-snippet.html

MINIMUM SIZE
Stacked 200 px / 1.75 in wide. Horizontal 280 px / 2.5 in wide. Smaller than that, use the icon.
